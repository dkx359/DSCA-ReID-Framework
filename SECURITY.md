# Security Policy

This repository is intended for authorized robustness evaluation, red-teaming research, and defense development for person re-identification systems.

Do not use this code to attack, evade, or interfere with systems without explicit permission.

## Reporting issues

If you find a security issue in this repository, please open a private security advisory on GitHub or contact the maintainers through the repository issue tracker with a minimal, non-sensitive description.

Please do not include private data, credentials, surveillance footage, or non-public system details in public issues.

## Scope

The lightweight backend in this repository is provided for code-structure validation and research extension. It is not intended to reproduce paper-level attack performance without integrating the corresponding pretrained components and authorized benchmark protocols.
